📱 WhatsApp OTP Template

Template for sending OTP via WhatsApp using Twilio

Hello {{NAME}}, Your AK BEAUTY STORE verification code is: {{OTP}} This code will expire in 5 minutes. If you didn't request this code, please ignore this message. Thank you, AK BEAUTY STORE Team

📋 Template Variables

{{NAME}} - User's name
{{OTP}} - 5-digit OTP code
{{EXPIRY}} - Expiry time (optional)

Note: For WhatsApp messages via Twilio, keep the message concise and under 1600 characters. WhatsApp messages are plain text, so formatting will be minimal.
